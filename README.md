# Hi, I'm Ayush 👋

AI/ML undergrad at **Chitkara University** (B.E. CSE, AI/ML · CGPA 9.39) who likes building things and then measuring whether they actually work.
I research **reliable and efficient ML**: grounded small language models, ML-driven hardware scheduling, and on-device inference.

🌍 Portfolio: **[thisisayushfr.vercel.app](https://thisisayushfr.vercel.app/)** · 🆔 ORCID: **[0009-0001-9042-0820](https://orcid.org/0009-0001-9042-0820)**

## 🔬 Research
- **Adaptive CPU–GPU Task Scheduling using Machine Learning in Heterogeneous Computing Environments**: first author, *under review at Machine Learning (Springer Nature)*. ML models that predict whether a workload should run on CPU or GPU, benchmarked on 2,400 workloads (98.25% accuracy). *Code will be released after publication.*
- **Retrieval-Grounded and Verified Meal Planning with Small Language Models** *(in progress)*: does retrieval from a structured food-composition dataset plus deterministic verification make SLM outputs more reliable?

## 🚀 Selected Projects
- **[Breakr](https://github.com/thisIsAyushFr/Skills-For-AI/tree/main/Breakr)**: a multi-agent security auditor for AI-built web apps. 10 specialized agents, zero dependencies, and 39 tests, packaged as a Claude Code skill that verifies every finding against the real code.
- **[StudyLens](https://github.com/thisIsAyushFr/StudyLens)**: a RAG study assistant (FastAPI + ChromaDB) with page-cited answers, a relevance threshold that refuses to guess, and quiz generation.
- **[NEXUS](https://github.com/thisIsAyushFr/Nexus-Emotion-Detection)**: an asteroid survival game that adapts to your frustration using near-misses, input hesitation, and optional face and voice signals. [Live Demo](https://c2c-event.vercel.app/)
- **[CareSync](https://github.com/thisIsAyushFr/CareSync)**: a hospital management platform for appointments, beds, and operational data. **Finalist, Vibe to Viable (100+ teams).** [Live Demo](https://caresync-vtv.vercel.app/)
- **[PromptForge](https://github.com/thisIsAyushFr/PromptForge)**: a browser extension that optimizes prompts for Claude (React + Vite).
- **[Gesture Racing Game](https://github.com/thisIsAyushFr/Gesture-Racing-Game)**: a computer-vision racing game controlled entirely with hand gestures.
- **EcoSort**: a TinyML CNN that classifies recyclable vs. non-recyclable waste on an Arduino Nano ESP32 with a camera, with no cloud involved (team project, Global Week).
